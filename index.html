Employee Request Management System

Proof of concept: one intake, automatic triage, tracked to closure.

New request

What happens next

After you submit, the system assigns a ticket ID, classifies the request by keyword scoring, sets priority and SLA, and routes it to a team queue. Nothing is triaged by hand.

Classification and SLA rules used by the prototype

Each keyword hit adds a point to a department. The highest score wins; a tie or zero hits goes to Other for manual triage.

Priority: P1 if the text contains an urgent keyword, P2 for Payroll, otherwise P3. SLA hours: P1 = 2, P2 = 8, P3 = 24.
